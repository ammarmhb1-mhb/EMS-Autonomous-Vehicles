# UCR Driving Dataset

This folder contains 80 CSV files from the UCR dataset.

## Details

- **Source:** University of California, Riverside (UCR)
- **Files:** 80 CSV
- **Samples:** 287,962
- **Distance:** 4,030.39 km
- **Year:** 2013

## Original Source

- **DOI:** https://doi.org/10.6086/D1FW9G
- **Repository:** Dryad Digital Repository

## Variables

- Time (HOUR, MINUTE, SECOND)
- Speed (km/h)
- Altitude (m)
- Road grade (%)
- Ambient temperature (°C)
- HV Battery Level (%)
- Battery current (A)
- Battery voltage (V)
- HVAC power (kW)
